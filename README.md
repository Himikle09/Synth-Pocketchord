# Synth-Pocketchord
Designing a pocketchord / synth / music player device.
Initially, I tested physically using an arduino, a breadboard, some button, and wires. The result was quite successful, but the practicality of such a system wasn't great. I decided to use this project to learn how to use KiCad and first designed a schematic and then a PCB. The purpose of the music player, is to have an array of larger buttons that controls notes. It would most likely have 7 notes with the button above being the note exactly an octave above the lower, and the lower button would be sort of a harmonizer button, to always be able to play a nice chord. The 12 smaller buttons on the right controll recording, looping, kick, snare, chord/notes and much more. The joystick controlls pitch and overall octave.
